\section{What is NES?}
\begin{frame}{NES predicts the next edit, including where it belongs}
% Pale-blue title highlight shared with the other content boxes.
\begin{block}{Next Edit Suggestions (NES)}
An AI-integrated IDE continuously uses recent interactions and project context to infer the developer's intent and proactively suggest the next code modification.
\end{block}
\par\vspace{3mm}

\textbf{Primary signal} & Local code near the cursor & Recent edits and broader project context\\[7pt]
\textbf{Suggested change} & Continue code at the cursor & Insert, delete, or replace code across lines or files\\[7pt]

\note{Use the paper's distinction as a conceptual comparison. Implementations vary; modern completion tools may also retrieve repository context. NES is distinguished here by proactive next-edit prediction and the repeated per-edit acceptance loop.}
\end{frame}
